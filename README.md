# Adding Machine Calculator

A vintage-inspired calculator built with plain HTML, CSS, and JavaScript. The interface is styled like a compact mechanical adding machine and includes a scrolling paper-tape calculation history.

## Features

- Addition, subtraction, multiplication, and division
- Decimal values, percentages, and positive/negative sign toggling
- Clear and equals controls
- Paper-tape history for completed calculations
- Clickable keypad with keyboard support
- Responsive layout for desktop and mobile screens
- Reduced-motion support for users who prefer less animation

## Getting Started

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.

You can also serve the folder with any local static file server if preferred.

## Keyboard Controls

| Key | Action |
| --- | --- |
| `0`-`9` | Enter a digit |
| `.` | Enter a decimal point |
| `+` | Add |
| `-` | Subtract |
| `*` | Multiply |
| `/` | Divide |
| `Enter` or `=` | Calculate the result |
| `Escape` | Clear the calculator |
